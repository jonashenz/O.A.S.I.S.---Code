02 / I2C-Adress-Problem

Die VL53L0X Adress-Kollision

Sequenzielles Adress-Mapping über XSHUT

Jeder VL53L0X startet festverdrahtet auf Adresse 0x29. Um Kollisionen auf dem gemeinsamen Bus zu verhindern, steuert die Firmware die Sensoren über separate XSHUT-Shutdown-Leitungen an:

Dynamisches Startup-Verfahren
  1. Alle XSHUT-Pins auf LOW ziehen (alle Sensoren deaktiviert).
  2. Sensor 1 aktivieren → Adresse auf 0x30 ändern.
  3. Sensor 2 aktivieren → Adresse auf 0x35 ändern.
  4. Sensor 3 aktivieren → Adresse auf 0x34 ändern.
03 / Debugging

Die I2C-Hürde & korrigiertes Pin-Mapping

Standard Board-Siebdruck

SDA (IO1) und SCL (IO2) sind intern fest mit dem USB-C Spannungsregler/GDI-Displaybus verschaltet. Externer Bus kollidiert unweigerlich.

Unsere Lösung

Freie Pin-Zuweisung im Code auf unkritische Analog-Eingänge (A4 / A5) und Drosselung auf 20 kHz.

04 / Algorithmus

Nicht-lineare Wahrnehmung

Weber-Fechner-Gesetz

Der menschliche Körper nimmt Reizänderungen logarithmisch wahr. Eine lineare Frequenzsteigerung würde keine gefühlte Verdoppelung der Dringlichkeit bewirken.

f(d) = f_min * (f_max / f_min) ^ t

Der Reiz wird im kritischen Nahbereich exponentiell skaliert, um eine physiologisch lineare Dringlichkeitskurve im Körper des Nutzers zu erzeugen.
